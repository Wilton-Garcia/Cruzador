Cruzador — instalação de teste

Requer macOS 14 ou posterior. O Wine incluído é x86-64; em Macs Apple Silicon, o macOS precisa disponibilizar Rosetta para executá-lo.

Instalar

  1. Abra a imagem Cruzador.dmg.
  2. Arraste Cruzador.app para Applications.
  3. Abra o aplicativo pela pasta Aplicativos.

Este pacote local usa assinatura ad hoc e ainda não foi notarizado. A validação local não estabelece aceitação pelo Gatekeeper em outro Mac.

Atualizar

  1. Encerre os programas Windows e o Cruzador.
  2. Faça uma cópia do aplicativo atual e exporte as bottles que deseja preservar.
  3. Arraste a nova versão para a mesma pasta e escolha substituir no Finder.

A biblioteca fica em ~/Library/Application Support/Cruzador, separada do aplicativo. Substituir apenas Cruzador.app não apaga essa pasta. Migrações suportadas preservam uma cópia do arquivo de biblioteca anterior.

Para voltar a uma versão antiga, preserve a biblioteca atual antes de restaurar aplicativo e backup compatíveis entre si. Uma versão antiga pode não ler o formato de uma versão nova.

Limites desta versão

Atualização manual. Não há atualização automática, assinatura Developer ID ou garantia de compatibilidade integral com programas e jogos Windows.
